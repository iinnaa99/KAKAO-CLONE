## 💡 주요 기능

| 기능        | 내용                        |
| --------- | ------------------------- |
| 친구 목록     | 친구 프로필, 상태 메시지 확인 및 관리    |
| 채팅방 목록    | 대화방 리스트, 최근 메시지, 알림 여부 표시 |
| 채팅방       | 실제 채팅 UI 구현, 대화 내용 표시     |
| 친구/콘텐츠 찾기 | 친구 검색, 추천 친구, 오픈채팅 탐색 기능  |
| 더보기 탭     | 설정, 쇼핑, 기타 부가 기능 모음       |
| 설정 화면     | 프로필 관리, 알림, 계정/보안 설정 관리   |
